## Instructions

1. Gather user requirements: brand name, industry, style, colors, and use cases.
2. Generate 3-5 logo concepts using DeepSeek V4's enhanced agent capabilities.
3. For each concept, provide:
   - Full-color version
   - Monochrome version
   - Reversed version (for dark backgrounds)
4. Expand into full brand identity:
   - Color palette (primary, secondary, accent, neutral)
   - Typography (heading, body, accent fonts)
   - Spacing and grid guidelines
   - Usage rules (minimum size, clear space, prohibited uses)
